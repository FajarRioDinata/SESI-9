1 📌 Review Sesi 8 – Builder Pattern

Builder Pattern digunakan untuk membuat objek kompleks secara bertahap. Method chaining memungkinkan fluent API yang lebih mudah dibaca.

class ConfigBuilder {
  ConfigBuilder host(String h) { return this; }
  ConfigBuilder port(int p) { return this; }
  Config build() { return Config(); }
}

// Contoh: Pizza.builder().size('large').addTopping('cheese').build()
💡 Inti: Memisahkan konstruksi objek dari representasinya. Method chaining mengembalikan this sehingga panggilan berantai natural.
2 ✨ Pengantar Extension Methods

Extension Methods adalah fitur Dart (sejak Dart 2.7) untuk menambahkan metode, getter, setter, atau operator ke tipe yang sudah ada tanpa mengubah kode asli. Analogi: memberikan kemampuan baru tanpa memodifikasi benda aslinya.

✅ Keuntungan: Kode lebih natural, readable, dan reusable.
3 ⚠️ Masalah Tanpa Extension Methods

Tanpa extension, kita sering membuat utility class seperti StringUtils yang kurang natural dan memecah alur baca kode.

class StringUtils {
  static String capitalize(String text) {
    if (text.isEmpty) return text;
    return text[0].toUpperCase() + text.substring(1);
  }
  static bool isEmail(String text) => text.contains('@');
}

void main() {
  var name = 'john';
  var capitalized = StringUtils.capitalize(name); // 'John'
  var isEmail = StringUtils.isEmail('test@mail.com');
  print('Capitalized: $capitalized');      // John
  print('Is email: $isEmail');             // true
}

🔴 Kekurangan: Tidak bisa dipanggil langsung pada instance, kode seperti prosedural.

4 ✅ Solusi: Extension Methods (Natural API)

Buat extension StringExtensions pada tipe String sehingga method dapat dipanggil langsung.

extension StringExtensions on String {
  String capitalize() {
    if (isEmpty) return this;
    return this[0].toUpperCase() + substring(1);
  }
  bool get isEmail => contains('@');
  String reverse() => split('').reversed.join();
}

void main() {
  var name = 'john';
  print(name.capitalize());        // 'John'
  print('test@mail.com'.isEmail); // true
  print('hello'.reverse());       // 'olleh'
}
🎯 Hasil: Kode lebih ekspresif dan berorientasi objek secara alami.
5-6 📦 Tipe yang Didukung & Contoh Generic Dasar

Extension dapat ditambahkan ke: built-in types (String, int, double, List, Map), custom classes, generic types (List<T>, Map<K,V>), dan nullable types.

extension IntListExtensions on List<int> {
  int get sum => fold(0, (total, item) => total + item);
  double get average => isEmpty ? 0 : sum / length;
}

void main() {
  var numbers = [1, 2, 3, 4, 5];
  print(numbers.sum);      // 15
  print(numbers.average);  // 3.0
}
💪 Mudah menambahkan helper method pada koleksi angka.
7 🛡️ Extension untuk Null Safety (Nullable types)

Menangani tipe nullable dengan aman menggunakan extension pada String?.

extension NullableStringExtensions on String? {
  String orEmpty() => this ?? '';
  bool get isNullOrEmpty => this == null || this!.isEmpty;
  bool get isNotNullOrEmpty => !isNullOrEmpty;
  String withDefault(String defaultValue) => this ?? defaultValue;
}

void main() {
  String? name;
  print(name.isNullOrEmpty);           // true
  print(name.withDefault('Guest'));    // 'Guest'
  name = 'Fajar';
  print(name.isNotNullOrEmpty);        // true
}
🚀 Best practice: Selalu handle nullable dengan aman, hindari runtime error.
8 🧬 Generic Extensions: List<T> Power

Extension generik sangat fleksibel untuk berbagai tipe data. Contoh: getOrNull, chunk (memecah list), dan distinct.

extension ListExtensions<T> on List<T> {
  T? getOrNull(int index) => (index < 0 || index >= length) ? null : this[index];
  List<List<T>> chunk(int size) {
    var chunks = <List<T>>[];
    for (var i = 0; i < length; i += size) {
      chunks.add(sublist(i, (i + size) > length ? length : i + size));
    }
    return chunks;
  }
  List<T> distinct() {
    var result = <T>[];
    for (var item in this) if (!result.contains(item)) result.add(item);
    return result;
  }
}

void main() {
  var numbers = [1, 2, 3, 4, 5, 6, 7];
  print(numbers.chunk(3));      // [[1, 2, 3], [4, 5, 6], [7]]
  print([1, 2, 2, 3, 3, 3].distinct()); // [1, 2, 3]
}
⚡ Generic extension meningkatkan produktivitas kode manipulasi koleksi.
9 🔒 Extension Tanpa Nama (Private / Library Scope)

Extension bisa dideklarasikan tanpa nama (anonymous extension) hanya untuk file/library yang sama, tidak bisa diimpor dari luar.

// File: date_utils.dart
extension on DateTime {
  String get toYYYYMMDD => '$year-${month.toString().padLeft(2, '0')}-${day.toString().padLeft(2, '0')}';
  DateTime get startOfDay => DateTime(year, month, day);
}

void main() {
  var today = DateTime.now();
  print(today.toYYYYMMDD);   // 2025-02-20 (contoh)
  print(today.startOfDay);
}
📁 Gunakan ketika hanya perlu utility dalam satu file dan tidak ingin mengekspos API global.
10 ⚠️ Konflik Nama Extension (Ambiguity)

Jika dua extension memiliki method dengan nama yang sama pada tipe yang sama, akan terjadi ambiguity error. Solusi: import dengan prefix atau show/hide.

// string_extensions.dart
extension StringCaseExtensions on String {
  String capitalize() => /* versi A */;
}
// text_utils.dart
extension TextUtilsExtensions on String {
  String capitalize() => /* versi B */;
}

// Solusi:
import 'string_extensions.dart' as se;
import 'text_utils.dart' hide capitalize;

void main() {
  var text = 'hello';
  // text.capitalize(); // ERROR: ambiguous
  se.capitalize(text); // pakai prefix
}
🧩 Rekomendasi: Gunakan nama extension yang unik dan import dengan prefix jika perlu.
11-12 📌 Ringkasan & Best Practices Extension Methods

✨ Ringkasan

  • Menambah method ke tipe yang ada
  • Sintaks: extension Nama on Type { }
  • Dukungan: method, getter, setter, operator
  • Generic extensions: extension <T> on List<T>
  • Nullable extension: String? dll

📐 Best Practices

  • Nama jelas StringExtensions, DateTimeUtils
  • Group by type satu file per tipe utama
  • Avoid overuse jangan jadikan semua utility sebagai extension
  • Null safety handle nullable dengan ?. atau orDefault
  • Dokumentasi tambahkan komentar /// untuk public extensions
// Contoh final praktis: extension terstruktur
extension DoublePrecision on double {
  String toFixed(int decimals) => toStringAsFixed(decimals);
}

void main() {
  double price = 19.999;
  print(price.toFixed(2)); // "20.00"
}
💡 Takeaway: Extension methods membuat kode Dart lebih ekspresif, namun gunakan secara bijak agar tidak membingungkan.
13 🧪 Studi Kasus: Extension Methods Pada Tipe Kustom

Selain tipe bawaan, extension juga powerful untuk class buatan sendiri.

class Product {
  final String name;
  final double price;
  Product(this.name, this.price);
}

extension ProductExt on Product {
  String get formattedPrice => 'Rp ${price.toStringAsFixed(0)}';
  bool get isExpensive => price > 1_000_000;
}

void main() {
  var laptop = Product('MacBook', 18500000);
  print(laptop.formattedPrice); // Rp 18500000
  print(laptop.isExpensive);    // true
}
🧠 Kapan memakainya? Ketika Anda ingin menambah fungsionalitas tanpa mewarisi class atau mengubah kode asli (misal dari package).
14 🏁 Penutup & Implementasi Nyata

Extension methods mendukung operator overloading juga, misalnya menambahkan operator + ke tipe tertentu. Contoh sederhana:

extension IntOperator on int {
  int operator [](int power) => this * power; // kreatif!
  bool get isEven => this % 2 == 0;
}

void main() {
  print(5[3]);  // 15 (5 * 3)
  print(10.isEven); // true
}

Kesimpulan: Extension methods pada Dart adalah mekanisme modern dan elegan untuk meningkatkan pengalaman developer, menjaga kode tetap bersih tanpa mengorbankan keamanan tipe. Selalu ikuti best practices, dokumentasikan, dan gunakan secara konsisten.
