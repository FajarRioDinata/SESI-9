Menambah method ke tipe eksisting
Apa itu? Extension methods memungkinkan kita menambahkan fungsi baru ke tipe yang sudah ada (String, int, List, dll.) tanpa mengubah kode asli. Tersedia sejak Dart 2.7. Analoginya seperti memberi "kemampuan baru" pada objek tanpa modifikasi internal.
Slide 3 ❌ Masalah Tanpa Extension Methods
Utility class kurang natural
Penjelasan: Tanpa extension, kita harus membuat kelas utilitas seperti StringUtils yang memanggil method secara statis. Kode menjadi kurang intuitif dan tidak mengalir secara natural dari instance. 
class StringUtils {
  static String capitalize(String text) {
    if (text.isEmpty) return text;
    return text[0].toUpperCase() + text.substring(1);
  }
  static bool isEmail(String text) => text.contains('@');
}

void main() {
  var name = 'john';
  var capitalized = StringUtils.capitalize(name); // 'John'
  var isEmail = StringUtils.isEmail('test@mail.com');
  print('Original: $name, Capitalized: $capitalized, Is email: $isEmail');
}
Slide 4 ✅ Solusi dengan Extension Methods
Sintaks natural & mudah dibaca
Penjelasan: Dengan extension, kita bisa langsung memanggil name.capitalize() atau 'test@mail.com'.isEmail. Contoh berikut mendefinisikan StringExtensions dengan method capitalize(), getter isEmail, dan reverse(). 
extension StringExtensions on String {
  String capitalize() {
    if (isEmpty) return this;
    return this[0].toUpperCase() + substring(1);
  }
  bool get isEmail => contains('@');
  String reverse() => split('').reversed.join();
}

void main() {
  var name = 'john';
  print(name.capitalize());          // 'John'
  print('test@mail.com'.isEmail);    // true
  print('hello'.reverse());          // 'olleh'
}

📘 Sintaks Extension Methods

Extension methods memungkinkan kita menambahkan fungsionalitas baru ke tipe yang sudah ada (built-in atau custom) tanpa harus mewarisi atau mengubah kode asli. Sintaks dasarnya adalah:

extension NamaExtension on TipeTarget { ... } — Di dalam blok, kita bisa mendefinisikan method, getter, setter, maupun operator.

Pola Dasar 
extension <NamaExtension> on <TipeTarget> {
    // Method, getter, setter, operator
    ReturnType methodName(Parameters) { ... }
    ReturnType get propertyName => ...;
    void set propertyName(Value) => ...;
    ReturnType operator +(Parameters) { ... }
}
Contoh lengkap: Extension pada DateTime 
extension DateTimeExtensions on DateTime {
    // Method: mengembalikan format tanggal dd/mm/yyyy
    String toFormattedString() {
        return '$day/$month/$year';
    }
    
    // Getter: mengecek apakah tanggal ini adalah hari ini
    bool get isToday {
        var now = DateTime.now();
        return year == now.year &&
               month == now.month &&
               day == now.day;
    }
    
    // Operator overloading: menambah Duration dengan operator +
    DateTime operator +(Duration duration) {
        return add(duration);
    }
}

void main() {
    var today = DateTime.now();
    print(today.toFormattedString());   // contoh: 29/5/2026
    print(today.isToday);               // true
    var nextWeek = today + Duration(days: 7);
    print(nextWeek.toFormattedString());
}
Catatan penting: Extension tidak bisa mengakses anggota private dari tipe target. Extension hanya menambahkan metode "tambahan", namun tidak mengubah struktur asli objek. Cocok untuk membuat API yang lebih ekspresif dan natural.
Didukung: method, getter, setter, operator overloading

extension IntListExtensions on List {
  int get sum => fold(0, (total, item) => total + item);

void main() {

Slide 6 🛡️ Null Safety Extension
Handle nullable dengan aman
Penjelasan: Extension pada tipe nullable (String?) memungkinkan kita memanggil method dengan aman tanpa harus melakukan null check secara manual, misalnya orEmpty() atau isNullOrEmpty. 
extension NullableStringExtensions on String? {
  String orEmpty() => this ?? '';
  bool get isNullOrEmpty => this == null || this!.isEmpty;
  bool get isNotNullOrEmpty => !isNullOrEmpty;
  String withDefault(String defaultValue) => this ?? defaultValue;
}

void main() {
  String? name;
  print(name.isNullOrEmpty);           // true
  print(name.withDefault('Guest'));    // 'Guest'
}
Slide 7 🔁 Generic Extensions
List<T> dengan method reusable
Penjelasan: Extension generik sangat powerfull. Contoh di bawah menambahkan chunk() untuk membagi list, distinct() menghapus duplikat, dan getOrNull() untuk akses aman. 
extension ListExtensions on List {
  T? getOrNull(int index) => (index < 0 || index >= length) ? null : this[index];
  List> chunk(int size) {
    var chunks = >[];
    for (var i = 0; i < length; i += size) {
      chunks.add(sublist(i, (i + size) > length ? length : i + size));
    }
    return chunks;
  }
  List distinct() {
    var result = [];
    for (var item in this) if (!result.contains(item)) result.add(item);
    return result;
  }
}

void main() {
  print([1,2,3,4,5,6,7].chunk(3));  // [[1,2,3],[4,5,6],[7]]
  print([1,2,2,3,3,3].distinct());  // [1,2,3]
}
Slide 8 🏷️ Extension Tanpa Nama
Hanya untuk library yang sama
Penjelasan: Di Dart, kita bisa membuat extension tanpa nama (anonymous extension). Biasanya digunakan dalam file yang sama atau library privat, tidak bisa diimpor dari luar. Akses terbatas pada lingkup file tersebut. 
// File: date_utils.dart
extension on DateTime {
  String get toYYYYMMDD => '$year-${month.toString().padLeft(2, '0')}-${day.toString().padLeft(2, '0')}';
  DateTime get startOfDay => DateTime(year, month, day);
}

void main() {
  var today = DateTime.now();
  print(today.toYYYYMMDD);   // contoh: 2025-01-22
  print(today.startOfDay);
}
Slide 9 ⚠️ Konflik Nama Extension
Mengatasi ambiguitas method
Penjelasan: Jika dua extension memiliki method dengan nama sama, terjadi konflik. Solusinya: import dengan prefix atau menggunakan show/hide. Contoh: import 'string_extensions.dart' as se; lalu panggil se.capitalize(text). 
// string_extensions.dart
extension StringCaseExtensions on String { String capitalize() => /* ... */; }

// text_utils.dart
extension TextUtilsExtensions on String { String capitalize() => /* berbeda */; }

// main.dart
import 'string_extensions.dart' as se;
import 'text_utils.dart' hide capitalize;

void main() {
  var text = 'hello';
  // text.capitalize(); // ERROR ambiguous
  se.capitalize(text); // menggunakan prefix
}
Slide 10 📌 Ringkasan & Best Practices
Panduan penggunaan extension methods
Ringkasan: Extension methods menambah method ke tipe yang ada, sintaks extension Nama on Tipe. Mendukung method, getter, setter, operator, bahkan generic. Best practices: nama jelas (StringExtensions), satu file per tipe utama, jangan berlebihan, tangani null safety dengan baik, serta beri dokumentasi. 
// Best practice contoh dokumentasi
/// Extension untuk memudahkan manipulasi String
extension StringExtensions on String {
  /// Mengubah huruf pertama menjadi kapital
  String capitalize() => isEmpty ? this : this[0].toUpperCase() + substring(1);
}

// Gunakan secukupnya, jangan terlalu banyak sehingga membingungkan.
Inti: Lebih natural, readable, dan reusable
